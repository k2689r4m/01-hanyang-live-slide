## 프로젝트명
한양대학교 실시간 참여형 강의 플랫폼

## 수행 시기
2020년

## 프로젝트 소개
교수가 온라인 강의용 슬라이드를 제작하거나 PPT/PPTX/PDF 파일을 업로드하여 강의를 진행하고, 학생들이 웹을 통해 실시간으로 동일한 슬라이드를 보며 수업에 참여할 수 있는 실시간 강의 플랫폼.

교수의 슬라이드 전환을 학생 화면에 실시간으로 동기화하고, 객관식·주관식 퀴즈, 제한시간, 점수 및 리더보드, 학생 반응, 채팅 등 참여형 강의 기능을 제공한다.

## 주요 기술
- PHP / Laravel 7
- Vue.js 2
- JavaScript
- Laravel Echo
- Laravel WebSockets
- Presence Channel
- MySQL 계열 관계형 DB
- Axios
- ImageMagick
- HTML / SCSS / Bootstrap

## 주요 기능

### 실시간 강의
- 교수/학생별 강의 화면 제공
- 강의실 단위 실시간 WebSocket 채널 구성
- 교수의 슬라이드 전환을 참여 학생 화면에 실시간 동기화
- 현재 강의 및 슬라이드 진행 상태 관리
- 실시간 강의 참여자 입장/퇴장 상태 관리

### 슬라이드 및 강의 콘텐츠
- 강의용 슬라이드 생성 및 편집
- 객관식, 주관식, 텍스트, 이미지, 텍스트+이미지 등 다양한 슬라이드 유형 지원
- Drag & Drop 기반 슬라이드 순서 변경
- 기존 강의 슬라이드 복사 기능
- 이미지가 포함된 문제 및 답안 구성

### PPT/PDF 변환
- PPT, PPTX, PDF 파일 업로드
- 서버에서 ImageMagick을 이용하여 문서를 페이지별 이미지로 변환
- 변환된 이미지를 강의 슬라이드로 자동 생성 및 연결
- 생성된 슬라이드를 웹 기반 강의 콘텐츠로 활용

### 실시간 퀴즈
- 객관식 및 주관식 문제 출제
- 퀴즈 시작/종료 상태 실시간 동기화
- 제한시간 설정 및 교수-학생 간 타이머 동기화
- 정답 여부 및 점수 처리
- 선착순 가점 기능
- 학생 답변 결과 집계 및 그래프 표시
- 누적 점수 및 리더보드 제공

### 실시간 커뮤니케이션
- 강의실별 실시간 채팅
- 실명/닉네임 기반 참여 지원
- 학생 반응 기능
- Presence Channel을 이용한 실시간 참여자 관리

### 기타 강의 관리
- 강의 및 수업 관리
- 공지사항
- 자료실
- Q&A 및 댓글
- 사용자 및 강의 참여자 관리
- 소셜 로그인

## 담당 업무
**Frontend / DB 설계 / Realtime / 문서 변환 기능 담당**

### Frontend
- Vue.js 기반 교수용/학생용 실시간 강의 화면 개발
- 강의 슬라이드 제작 및 편집 UI 개발
- 객관식·주관식 퀴즈 화면 구현
- 퀴즈 결과 및 그래프 UI 구현
- 실시간 채팅 및 학생 반응 UI 구현
- 슬라이드 Drag & Drop 및 강의 진행 인터페이스 구현

### DB 설계
- 강의, 수업, 슬라이드, 참여자, 답변, 진행상태, 메시지 등 서비스 주요 데이터 구조 설계
- 실시간 강의 진행 및 퀴즈 기능을 지원하기 위한 관계형 데이터 구조 설계

### WebSocket / 실시간 통신
- Laravel WebSockets 및 Laravel Echo 기반 실시간 통신 기능 구현
- 강의실별 Presence Channel 구성
- 교수의 슬라이드 변경 이벤트를 학생 화면에 실시간 동기화
- 퀴즈 시작/종료 및 타이머 동기화
- 참여자 입장/퇴장 상태 처리
- 실시간 채팅 및 강의 참여 이벤트 처리

### PPT/PDF 변환
- PPT/PPTX/PDF 강의자료 업로드 기능 구현
- ImageMagick을 이용한 서버 측 문서 이미지 변환 처리
- 문서 페이지별 이미지 생성 및 강의 슬라이드 자동 연결 기능 구현

## 프로젝트 내 역할
첫 실무 프로젝트로 참여하여 프론트엔드 개발뿐 아니라 DB 설계, WebSocket 기반 실시간 통신 및 PPT/PDF 문서 변환 기능을 담당했다.

백엔드의 일반 API 및 주요 서버 비즈니스 로직은 다른 개발자가 담당했으며, 실시간 강의에 필요한 클라이언트 기능과 실시간 통신 영역을 중심으로 개발했다.
